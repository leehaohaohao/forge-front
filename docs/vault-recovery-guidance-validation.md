# 恢复文件下载与锁定引导

2026-10-25

用户在创建后进入已锁定草稿界面，尚未下载文件却仍看到“继续确认”，无法完成验证。该界面存在内存草稿，不能据此认定整页刷新；代码在失焦、隐藏或空闲时自动锁定。

修复：
- 记录并展示草稿因失焦、页面隐藏或空闲而锁定的原因，不放宽自动锁定。
- 未发起下载的锁定草稿不再显示无效的密码/继续入口，而是明确提示放弃草稿、重新生成、先下载。
- 已发起下载的草稿继续支持输入刚设置的密码，验证原文件；文案只声称“发起下载”，不把点击当作已成功落盘。
- 生成后突出“下载恢复材料”按钮，说明下载不会自动弹出，之后需验证再保存；下载后提示浏览器下载记录及文件名。

验证：生产构建和类型检查通过；scripts/test-vault-page.cjs 覆盖未下载/已下载锁定草稿、放弃和显式清理、同一恢复文件继续确认、完整密钥操作。接口为 fixture，未处理用户数据或部署生产。
