# 用户流程补齐：前3验收

2026-10-27。前端基于前1 520c903、前2 129921e；后端F3基于96f3967。全部开发在WSL项目进行。

## 实现

- 同时读取F1真实批次/审计/冻结与F3任务，核对批次及版本，当前审计和任务均完成才推进。完成时间存在但当前审计失败不能显示成功。请求失败保留待确认进度与重试，隐藏/离页取消读取。
- 切换状态变化刷新密钥列表，锁定保留完成进度；已迁移记录解锁后可查看、复制、新增。历史迁移节点保留，无历史用户省略。
- 展开详情查看任务回执、负责人、数量、切换/审计/备份/恢复/文件处置时间。后续失败在当前区域直接可见，备份或恢复失败不伪装成通过，也不自行冻结已切换账户。
- 复用vault_export重认证、版本校验及B1导出，严格检查记录、归属、字段和密文结构。分别下载JSON与原始字节SHA256；未迁移备份明确不完整。错误、429等待、锁定/离页取消受控。
- /app/recovery-check无需登录，检测到登录会话要求转至隐私窗口。每次验证使用新Worker，仅读取本地File，重新解开恢复封装并逐包解密验证；不继承原Worker密钥，不访问业务HTTP，不持久化、不回传业务明文。错误材料/摘要/篡改失败；含历史记录不算完整。隐藏、停止、离页终止Worker并清理引用。
- VITE_VAULT_MIGRATION_ENABLED默认false；关闭时保留只读状态，申请与本地执行不可用。开启须同步发布F1/F2/F3和SQL004～008，经授权完成预发布检查。前端开关不替代后端鉴权/冻结检查。
