# 保险库与历史密钥迁移操作说明

2026-10-27。面向用户；管理员操作见后端 docs/token-vault-migration-runbook.md。

## 首次使用与日常操作

1. 设置独立于账号登录密码的长口令，创建本地保险库。
2. 下载恢复文件，从文件重新输入恢复密钥验证，最后保存加密保险库。仅下载不代表保存完成。
3. 无历史数据时直接开始使用。有历史数据但没有冻结时，也可以先新增密钥。
4. 日后点击“新增密钥”，锁定时先解锁，再填写空白表单。正常锁定不重置准备进度。

查看30秒后隐藏；隐藏页面、离页、5分钟无操作或手动锁定会清理本地秘密。浏览器保存提示或下载提示单纯获得焦点不会锁定。剪贴板内容需自行清理。名称、供应商、分类、备注是明文，不要填写秘密。

## 历史迁移

1. 在迁移步骤申请准备。申请不会立即冻结，也不会导出原值。
2. 等待管理员确认备份、冻结并安全交付文件。未领取的申请可以取消；冻结不能由用户随意取消。
3. 解锁，选择管理员通过可信加密渠道交付的源文件，输入账号登录密码确认身份，开始本地校验。不要把源文件上传到普通附件或公开链接。
4. 浏览器只上传密文；实际读回解密核对后提交回执。断网可重试，刷新后需重新解锁、选择源文件；已提交记录以服务器读回结果为准。
5. 显示“等待切换”时仍不能查看历史记录。管理员切换并通过审计后，步骤推进到“开始使用”，列表自动刷新。锁定时先解锁才能查看或复制。

网页处理上限8 MiB、2000条。超限或分片备份请联系负责人使用受支持的本地工具。迁移失败或状态不明时刷新状态，向负责人提供任务回执；不发送独立密码、恢复密钥或主密钥。未开放执行入口时，需要管理员确认部署及验收开关。

## 加密备份与独立恢复验证

1. 展开“加密备份与独立恢复验证”，输入账号登录密码，准备备份。
2. 分别下载加密备份和对应 .sha256 摘要，确认浏览器实际保存。摘要用于检查文件完整性，不能代替可信交付或保管来源。
3. 恢复文件与加密备份分别保管。恢复文件本身不包含业务密钥数据。
4. 将“独立恢复验证”地址复制到新的隐私窗口或干净浏览器。无需登录，选择备份、摘要及当时配套的恢复文件，确认后验证。
5. 验证页使用新的本地计算进程，不复用原保险库会话；不向业务接口发送文件或恢复材料，不写回记录。隐藏或关闭页面会停止验证；失败后重新选择文件。
6. “独立恢复验证通过”只代表当前选中备份的全部密文可恢复。含待迁移记录时明确显示不完整，不能宣称完整恢复。更换独立密码/恢复材料后，旧备份需要其原配套恢复材料。

迁移结果详情中的管理员备份、独立恢复、临时文件处置是分别登记的状态。网页下载或验证不会自动改变这些登记；管理员需核对实际快照与结果后按运维流程登记。分片备份继续使用现有 verify-shards 工具，不合并或覆盖原文件。
